Section 2: Creating the Form

Step 1: Create Project Folder & File in www

  1. Go to C:\wamp64\www\ and create a new folder named student_app.
  2. Inside student_app, create a new file named index.php.

Step 2: Add the HTML Form

Paste the form code below into index.php:

index.php 
<html>
<head>
    <title>Student Form</title>
</head>
<body>

    <h2>Student Registration Form</h2>

    <form method="POST" action="">
        <label>Roll No:</label>
        <input type="number" name="rollno" required><br><br>

        <label>Name:</label>
        <input type="text" name="name" required><br><br>

        <label>Department:</label>
        <input type="text" name="dept" required><br><br>

        <button type="submit" name="submit">Submit</button>
    </form>

</body>
</html>

Key Form Parts Explained

  • <form method="POST" action=""> — Sends the entered data securely via POST to the same page (action="") so our PHP code at the top can catch it.
  • <label> — Displays the text title next to each input box so the user knows what to type.
  • type="number" / type="text" — Controls what kind of data the box accepts (numbers only for Roll No, normal text for Name and Department).
  • name="rollno" (and name="name", name="dept") — The exact variable keys PHP uses to grab the input values later (e.g., $_POST['rollno']).
  • required — Stops the form from submitting if a box is left empty.
  • <button type="submit" name="submit"> — Triggers the form submission and lets PHP check if the button was clicked using isset($_POST['submit']).

Other Input Options

Aside from standard text and number boxes, forms also use radio buttons and dropdown lists to give users fixed choices.

1. Radio Buttons

Radio Input 
<label>Gender:</label>
<input type="radio" name="gender" value="Male" required> Male
<input type="radio" name="gender" value="Female"> Female<br><br>
  • type="radio" — Lets the user pick only one option from a small group. Both buttons must share the exact same name="gender" so selecting one automatically unselects the other, while value="..." holds the text sent to PHP.

2. Dropdown Menu (Select Box)

Dropdown Input 
<label>Course:</label>
<select name="course">
    <option value="MCA">MCA</option>
    <option value="BCA">BCA</option>
    <option value="BTech">BTech</option>
</select><br><br>
  • <select name="course"> & <option> — Creates a dropdown menu. The name goes on the outer <select> tag, and the selected <option value="..."> is what PHP receives.

Task: Add both the radio buttons and dropdown snippet inside the <form> tags of your index.php file right above the Submit button, then refresh localhost to test them.

Section 4: Connecting Database & Inserting Data

Step 1: Add the PHP Connection & Insert Code

Open index.php inside C:\wamp64\www\student_app\ and paste the PHP code below right after the closing </html> tag:

index.php (Add below </html>) 
<?php
if (isset($_POST['submit'])) {
    extract($_POST);
    $con = mysqli_connect("localhost", "root", "", "college_db");
    $sql = "INSERT INTO students (rollno, name, dept, gender, course) VALUES ('$rollno', '$name', '$dept', '$gender', '$course')";
    $q = mysqli_query($con, $sql);
    if ($q) {
        ?>
        <script>
            alert("Success");
        </script>
        <?php
    } else {
        ?>
        <script>
            alert("Something went wrong");
        </script>
        <?php
    }
}
?>

Key PHP & MySQL Parts Explained

  • if (isset($_POST['submit'])) — Checks if the Submit button was clicked so the database code only runs on form submission.
  • extract($_POST); — Automatically converts all submitted form inputs (name="rollno", name="name", name="dept", name="gender", name="course") into matching PHP variables ($rollno, $name, etc.).
  • mysqli_connect("localhost", "root", "", "college_db") — Connects PHP to your MySQL database (college_db) using the default WAMP username (root) and empty password ("").
  • INSERT INTO students (...) VALUES (...) — Inserts a new student record into the students table (skipping id since AUTO_INCREMENT generates it automatically).
  • $q = mysqli_query($con, $sql); — Runs the SQL query against the connection $con. If the database connection fails or the query has an error, $q returns false; if both succeed, $q returns true.
  • if ($q) { ... } else { ... } — Checks whether the connection and insertion succeeded. Notice how ?> temporarily closes PHP so standard HTML <script>alert("Success");</script> can pop up a browser alert, then <?php reopens PHP for the else block (which pops up "Something went wrong" if it failed).
Pro Tip — Skip Typing the SQL Query Manually:
  1. Open your students table in phpMyAdmin and click the Insert tab at the top.
  2. Scroll down and click Preview SQL at the bottom.

  3. Copy the generated INSERT INTO ... query, paste it into your $sql = "..."; string in VS Code, and replace the empty quotes with your PHP variables ('$rollno', '$name', etc.) in order.

Step 2: Test & Verify in phpMyAdmin

  1. Open http://localhost/student_app/index.php in your browser, fill out the form, and click Submit.
  2. Click OK on the Success popup alert.
  3. Open phpMyAdmin, go to college_db → students, and click the Browse tab to confirm your new record is saved.
